# 🌀 Simple Lightweight Preloader

**A stable, lightning-fast, and customizable page preloader for WordPress without any external dependencies.**



## 📖 Overview

**Simple Lightweight Preloader** is a highly optimized WordPress plugin designed to give your website a polished, professional feel by masking page load times with a sleek loading animation.

Built with performance in mind, this plugin injects CSS and Vanilla JavaScript directly into the DOM—meaning **zero extra HTTP requests**, zero bloat, and no reliance on heavy external libraries like jQuery for the frontend.

## ✨ Key Features

* 🚀 **Extremely Lightweight:** Inline CSS and JavaScript execution to ensure maximum performance without extra file requests.
* 🎨 **Fully Customizable:** Easily change the background color and spinner color to match your brand identity directly from the WordPress admin panel.
* ♿ **Accessibility Ready:** Built-in support for `prefers-reduced-motion`, ensuring users who prefer less animation see a static, comfortable loading screen.
* ⚡ **Memory Optimized:** Automatically removes the preloader node from the DOM once the transition completes, freeing up browser memory.
* 🛡️ **Clean Codebase:** Object-oriented PHP structure using WordPress best practices.

## 🛠️ Installation

### Option 1: Via WordPress Dashboard (Recommended)

1. Navigate to **Plugins > Add New** in your WordPress dashboard.
2. Click on **Upload Plugin** at the top of the page.
3. Select the `simple-lightweight-preloader.zip` file and click **Install Now**.
4. Once installed, click **Activate**.

### Option 2: Manual Installation via FTP

1. Extract the downloaded `simple-lightweight-preloader.zip` file.
2. Upload the extracted folder to the `/wp-content/plugins/` directory on your server.
3. Navigate to **Plugins > Installed Plugins** in your WordPress dashboard.
4. Locate **Simple Lightweight Preloader** and click **Activate**.

---

## ⚙️ Usage & Configuration

Configuring the preloader is incredibly simple:

1. Go to your WordPress Admin Dashboard.
2. Navigate to **Settings ➔ Simple Preloader**.
3. Toggle the **Enable Preloader** checkbox.
4. Use the intuitive color pickers to select your desired **Background Color** and **Spinner Color**.
5. Click **Save Changes** and visit your website's frontend to see it in action!
